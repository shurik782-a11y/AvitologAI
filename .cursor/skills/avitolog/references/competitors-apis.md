# Конкуренты: бесплатные API / e-сервисы

## Итог

**Бесплатного публичного API «все объявления ниши / конкуренты» у Авито нет.**  
Официальный API (`developers.avito.ru`) отдаёт в основном **свои** объявления кабинета (Items, Stats, Autoload) по OAuth — не чужой поиск.

## Что реально работает бесплатно сейчас

1. **Импорт CSV/XLSX** в AvitologAI (`POST .../competitors/import`) — любой e-сервис, который умеет экспорт таблицы.
2. **Аналитика спроса Авито** в кабинете (входит в тариф Профи) — ручной разбор запросов, не API для нас.
3. **Trial** сторонних сервисов (обычно 3–7 дней, потом платно): KonkurentAuto, LikeStats, парсеры («Эхолот» / A5 и т.п.) — почти всегда Excel, редко открытый free API.

## Не подключаем «как бесплатный API»

- Неофициальный скрейпинг Авито (ToS / блокировки / нестабильность).
- Платные API парсеров без явного ключа в Variables от пользователя.

## Рекомендация для продукта

Оставить **универсальный импорт таблиц** как основной free-путь.  
Нативный API e-сервиса — только когда заказчик даёт **имя сервиса + пример API/таблицы**.
