# Orchestrator JSON

Reply JSON (no markdown fences preferred):

```json
{
  "title": "...",
  "description": "...",
  "image_prompt": "...",
  "analysis": "...",
  "need_images": true
}
```

`need_images`: true when user wants a listing photo / creative visual; false for text-only, edits to copy, or explicit «без фото».
